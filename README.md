## 🛠️ How GitHub Sync Works

1. **Connect** your GitHub account on [neetcode.io/profile/github](https://neetcode.io/profile/github)
2. **Auto-commit** — every accepted submission is pushed automatically
3. **Bulk Sync** — push all past solutions at once from settings
4. **Manual sync** — sync or remove individual submissions from any problem page
